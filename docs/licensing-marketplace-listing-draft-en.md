## Title

Global Support Radar — Worldwide Grants & Benefits Discovery Platform

## Short description

A bilingual, mobile-friendly discovery platform that helps people and organisations navigate official public-support, grant, benefit and funding sources by country and category.

## What is included

- Responsive web application with Hungarian and English interface.
- Country and category navigation across public-support topics.
- Search, filters, saved items in the visitor's browser, shareable search URLs and CSV export.
- Progressive web app support and offline application shell.
- Source registry and automated discovery/update scripts for selected official sources.
- Early organisation-reporting and partner-discovery components.
- Project documentation and setup instructions, subject to the final verified delivery manifest.

## Important scope and limitations

This is an early-stage MVP/beta, not a complete worldwide grants database. Coverage varies significantly by country and programme. Some entries are official source links or discovery leads, not verified open calls. The platform does not determine legal eligibility, submit applications, guarantee funding, or guarantee that a programme is currently open.

The current public GitHub repository means some source code is already publicly viewable and forkable under GitHub's platform terms. The listing must not claim that the code is exclusive to paying buyers. The exact licensed file set and delivery bundle must be reviewed before publication.

No users, customers, revenue, business entity, domain, hosting account, customer list, or future income are included. No maintenance, uptime commitment, support, customisation or service-level agreement is included unless separately agreed in writing.
