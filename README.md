# Global Support Radar

**Worldwide Government Grants and Benefits Finder**

A mobile-friendly, bilingual (Hungarian/English) starting version of a worldwide public-support directory.

## Current version
- Responsive landing page
- Hungarian and English interface
- Country selector and category filters
- Search across illustrative entries
- Clear warning that current entries are demo content

## Important
This repository does **not** yet contain a verified live grants database or automatic worldwide monitoring. No demo entry should be treated as an active benefit or application opportunity. Real listings must be added only after checking an official government or local-authority source, eligibility rules, dates and application URL.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After GitHub publishes the site, its address will be shown on the Pages settings screen.

## Roadmap
- Identify authoritative government data sources country by country.
- Add a reviewed data model with original-language source text, translated summary, eligibility, deadlines and official links.
- Implement scheduled collection only through permitted APIs, feeds or compliant access methods.
- Add review, expiry and update tracking before showing listings as current.
- Add more interface languages and accessibility improvements.

## Disclaimer
Global Support Radar is an independent information project and is not affiliated with any government. Always confirm current eligibility and application requirements with the official programme provider.
